## ✨ ماذا تفعل هذه المهارة؟

بعد التثبيت، يتحول الـ AI الخاص بك إلى **مهندس QA محترف لتطبيقات الموبايل** قادر على:

- 🏗️ **مراجعة المعمارية** — أنماط التصميم، المكتبات، هيكل المجلدات، الترابط بين المكونات
- 🎨 **اختبار UI/UX** — الواجهات، النماذج، الأزرار، الاستجابة، إمكانية الوصول، الوضع الداكن
- 🧠 **الاختبار الوظيفي والمنطقي** — قواعد العمل، انتقالات الحالة، الحسابات، سير المصادقة
- 🔒 **التدقيق الأمني** — تغطية كاملة لـ OWASP Mobile Top 10، لا تنازل عن الأمان
- ⚡ **تحليل الأداء** — تسريب الذاكرة، انتهاكات الـ Main Thread، وقت البدء، استهلاك البطارية
- 📱 **التوافق مع المنصات** — Android وiOS، الصلاحيات، الروابط العميقة، الإشعارات
- 🌐 **مرونة API والشبكة** — معالجة أخطاء كل HTTP Status Code، الوضع غير المتصل، التخزين المؤقت
- 🔄 **إدارة الحالة والبيانات** — Race Conditions، اتساق البيانات، سلامة قاعدة البيانات
- 🛡️ **منع الأخطاء والأعطال** — Null Safety، معالجة الأخطاء العالمية، الحالات الحدية
- ✅ **التسليم النهائي** — ملخص تنفيذي، مصفوفة إثبات الفحص الشامل
- 🔧 **الإصلاح المُهيكل (Phase 11)** — إصلاح الأخطاء المكتشفة بشكل آمن عبر مراجعة دقيقة (Diff) مع فحص أمان تلقائي لكل كود جديد.
- 🏪 **جاهزية النشر التجاري (Phase 12)** — التحقق من سياسات المتاجر (Google و Apple)، حماية بوابات الدفع (Stripe/Paypal)، وتأمين الاشتراكات قبل النشر الفعلي.

## 🛡️ نظام مكافحة الكسل المدمج

المهارة مصممة لـ **إجبار الفحص الشامل** حتى على الـ AI الذي يميل لتخطي الخطوات.  
4 آليات مدمجة تجعل التخطي مستحيلاً:

### ١. استشهادات إثبات العمل (65 كحد أدنى)
كل ملاحظة **يجب** أن تحتوي على مسار الملف الدقيق، رقم السطر، والكود المنسوخ فعلياً.  
`❌ ممنوع: "راجعت المصادقة ولم أجد مشاكل"`  
`✅ مطلوب: "في lib/services/auth_service.dart:45-52، التوكن مخزن بدون تشفير..."`

### ٢. بوابات المراحل الإلزامية (9 بوابات)
كل مرحلة من المراحل العشر تحتوي على Checklist منظمة يجب استكمالها بالأدلة قبل الانتقال للمرحلة التالية.

### ٣. نقاط التوقف الإجبارية
بعد كل مرحلة، يجب على الـ AI إخراج تقرير منظم والانتظار للإقرار قبل المتابعة.

### ٤. مصفوفة التحقق المرجعية
المرحلة النهائية تطلب مصفوفة تثبت فحص كل ملف مع عدد الاستشهادات — أي مرحلة تظهر 0 ملفات يُعلن فيها الفحص ملغياً.

## 🔍 مثال على صيغة الاكتشاف

```markdown
### 🔴 [F001]: توكن المصادقة مخزن بدون تشفير

**الموقع:** `lib/services/auth_service.dart:67-71`
**الفئة:** الأمان
**التأثير:** التوكن متاح لأي تطبيق يمتلك صلاحية root — اختطاف كامل للجلسة

**الكود الإشكالي:**
```dart
// السطور 67-71
final prefs = await SharedPreferences.getInstance();
prefs.setString('auth_token', response.token);
prefs.setString('refresh_token', response.refreshToken);
```

**لماذا هذه مشكلة:**
SharedPreferences يخزن البيانات كنص XML عادي على Android. أي تطبيق
يمتلك صلاحية root، أو أي استخراج للنسخ الاحتياطية، يكشف التوكن كاملاً.

**الإصلاح:**
```dart
final storage = FlutterSecureStorage();
await storage.write(key: 'auth_token', value: response.token);
```
**المراجع:** OWASP M9 - تخزين البيانات غير الآمن
```
